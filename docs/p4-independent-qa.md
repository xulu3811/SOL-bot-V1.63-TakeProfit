# P4 独立 Codex QA

状态：独立 Codex QA 的 28 项离线测试通过。本报告不是 Cursor/Grok 外部审计；指定外部审计尚未执行，不能据此宣布获得实盘资格。

独立复核重点为资金守恒、风险边界和权限状态。生产资金、真实交易和私有 API 不在本次 QA 操作范围；使用隔离临时 SQLite 与合成输入验证。

## 验收参考

- 高水位 2000，净值 1900：恰好 5%，必须硬锁；1900.0001 不因舍入误锁。
- 净值包含机器人拥有的现金、仓位与 BNB，不能把未授权手动资产加入净值或卖出额度。
- 充值、提现本身不能抹掉亏损状态；零、负、非有限净值必须保持拒绝新入场。
- 同一意图重放不能多预留；相同 ID 改金额、账户、symbol 或期限不能取得旧许可。
- 两笔 700 的订单最多占两槽，第三笔拒绝；入场费用也需要预留。
- 部分成交从未成交预留转为实际持仓，不能重复算两槽，不能同时重复扣现金和冻结本金。
- 取消请求与已确认取消必须区分；未知订单仍占用资金与槽位，不能超时直接释放后重开。
- 硬锁、LIVE OFF 与服务异常不能删除原持仓保护或伪报平仓。
- 手动资产减少、余额不一致必须暂停冲突交易；卖出不得超过授权归属和真实可用量。
- BNB 价值恰好 3 不触发，低于 3 才触发；重复候选不得重复占用，每次约 10，主动补充后不超过 20。
- 数据库异常应事务回滚；决策/成交/资金流幂等键不可覆盖不同负载。
- 重启不能清空高水位、硬锁、持仓、预留或恢复旧 LIVE ON；P4 所有最终真实交易许可均拒绝。

其中资金参考使用 2000 初始净值、1950 亏损后净值、±500 外部现金流；流入流出后净值/高水位比率保持 0.975。部分成交参考为 200 SUI × 0.99 + 0.198 费用：剩余现金 1801.802，现金+持仓成本+费用=2000，剩余入场预留 500，已成交与未成交总风险为 7.7，重放成交不重复扣减。并发三笔 700 输入只允许两笔规划预留，本金和入场费合计 1401.4。

测试还覆盖精确 5% 触发、略低于 5% 不触发、取消待确认保留额度、未知订单与未知 BNB 补充不能被余额快照清除、未授权资产卖出、托管撤销后的旧意图重验、重启保护与授权意图保留、主账户多余资产排除、缺失价格拒绝新入场、最终 LIVE 门拒绝、独立备份还原、schema 身份变化拒写和事务回滚。

## 独立发现与修复验证

1. 初版 Guardian 的 reservation INSERT 使用 14 个占位符而表为 13 列，正常预留路径失败。主开发修复后并发预留及幂等测试通过。
2. 初版托管卖出对旧 intent 直接返回 ALLOW，绕过撤销后的权限检查。独立测试先复现失败，主开发改为重复意图也重新检查权限、余额与新鲜度后通过。
3. 初版 UNKNOWN 入场订单在普通余额对账后允许另一笔新入场。独立测试先复现失败，主开发保留未知订单阻断后通过；未知 BNB 补充同样纳入回归。
4. 最后只读复核发现 UNKNOWN 订单收到部分成交后被改为 PARTIAL，使余单未知状态可能被普通余额对账消除。主开发改为保留 UNKNOWN，新增 `test_p4_integration.P4Integration.test_partial_fill_does_not_resolve_unknown_remainder`；已只读核对服务器测试记录，该项为 `ok`。完整意图执行入口的类型检查与旧 LIVE 数据库读取也已纳入异常保护。
