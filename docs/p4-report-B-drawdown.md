# P4 报告B：高水位与风险边界

5%硬阈值未修改。机器人净值 = 分配现金 + ROBOT_OWNED资产按新鲜价格估值，包含 BNB；已记账手续费从现金扣除。MANUAL_UNMANAGED、MANUAL_CUSTODIED 均不自动进入机器人净值。价格缺失或过期时将净值有效时间清零，禁止使用旧盈利值授权。

高水位采用单位净值法。资金份额 U，净值 E，单位高水位 N，当前高水位 H=U×N。外部资金流 F 按当前单位净值增减份额：U'=U×(E+F)/E，H'=U'×N；保持原回撤比例。例如 E=1950、H=2000，流入500后仍为2.5%回撤，避免简单 H+=500 稀释风险。流出必须满足现金、预留和正净值约束，并再次进入待对账状态。资金流接口由可信管理边界提供，不用于自动发现主账户资产。

E≤0.95H 触发持久硬锁。锁产生 CANCEL_ENTRY 待办，保留余单额度直到执行端确认所有已成交数量和撤单终态。不会伪造已撤销，不市价全平；仓位和保护记录保留。普通 LIVE ON 无法解锁。管理员入口 `python -m solbot.risk.admin` 要求 OS root、请求ID、原因及用户授权引用；解锁审计保存当时风险状态，保留高水位且转 PAUSED。仍处于5%回撤时下一次估值重新锁定。本阶段未在生产执行解锁。

单笔300–700、最多两笔、总策略本金1400。评分额度300+400×(score−75)/25；T1单笔风险预算0.4%，并发总预算0.8%，损失计算计入止损距离、双边费率和滑点。R1的研究预算0.25%被保留，但其实际入场始终拒绝。低于300容量不抬高到最低门槛。两笔700并发占位后第三笔拒绝。

部分成交把余单本金/风险转入持仓本金/风险，已付费扣现金，避免同一份资金与持仓槽位重复占用。未知余单即使出现部分成交也保持 UNKNOWN，余额快照不能单独恢复新入场。

测试：`test_p4_independent_qa.py` 的独立参考与 `test_p4_integration.py` 生命周期测试。每项输入和预期断言、实际状态、版本及源哈希见 `data/p4-server/data/p4-test-evidence.json`。边界为合成隔离测试，不是实盘成交验证。
