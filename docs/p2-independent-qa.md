## 已验证的实现

- **指标数学与时间边界。** EMA 使用首个周期的 SMA 初始化，RSI、ATR、ADX 使用明确的 Wilder 初始化与递推。独立几何权重参考公式验证 RSI、EMA、ATR、ADX。RVOL 的基准是前 20 根成交量，当前根被排除。VWAP 定义为最近 20 根的报价成交额总和除以基础资产成交量总和。策略使用最多 120 根已完成 K 线，至少 60 根预热，筛选 `close_time <= as_of_ms`，并核验周期对齐、连续性和最新应有收盘时间。
- **策略与评分。** T1 和 R1 均有未替换真实指标函数的正向 OHLC 测试，以及假突破、继续下跌、买方恢复不足和数据未就绪的拒绝测试。硬性拒绝原因独立于分数生效。执行质量尚未观测时保留风险标记，波动率通过仅取得执行因子的 7.5/15 分。指标阈值、120 根初始化范围及该分配均作为初始研究定义记录。
- **持久调度。** 正式结果、来源摘要和 checkpoint 在同一事务中保存。重复事件不再计算正式结果，同一 5m 候选最多产生一个接受意图。历史追赶产生的过期候选保持拒绝，回放库具有独立模式标记，运行时消费入口拒绝该模式。读取市场库采用只读连接，缓存有界。
- **交易对与账户隔离。** SOL/SUI 使用独立市场文件、明确 symbol 约束和所有权检查。空库所有权也被检查。策略记录、执行文件和账户绑定 symbol/account/channel；SUI 数据不可用的测试保持 SOL 服务可用。写入前的用途检查阻止行情、策略、LIVE 和影子账本误共用文件。
- **LIVE 默认拒绝。** 首次状态为 LIVE_OFF。已认证 ON 请求返回 DENY_NOT_READY，完整 Guardian、私有适配和保护单状态机验收前始终拒绝实盘许可。即使测试直接写入 LIVE_ON，Guardian 仍拒绝执行，R1 有独立拒绝结果。HARD_LOCKED 经 OFF、ON 和重启保持锁定，旧 LIVE_ON 重启进入 PAUSED。
- **零私有调用边界。** 执行测试的 secret loader、私有客户端工厂、订单方法 spy 均为零调用，相关测试同时禁止 socket 连接。源码路径没有可执行的实盘订单传输实现。SOL-shadow 路由拒绝跨账户/跨标的请求，影子失败路径不会转入实盘。零调用结论覆盖所测机器人路径与所检查实现。
- **虚拟账本。** 初始资金 2,000 USDT，300–700 USDT 下单范围、两笔仓位/挂单槽位及费用预留在事务内处理。限价委托先保持 PENDING，只有后续符合价格和时效要求的报价能撮合。账本包含虚拟买卖、资金占用、费用、持仓、订单与信号关联；重复请求、并发预留、过期和重启都有回归覆盖。5% 回撤锁定、取消挂单及虚拟清仓在事务内完成。

本地 LIVE CLI 的变更操作要求 OS 管理员权限，服务端 SQLite 状态是权威来源。P2 提供本地控制及抽象 Compose repository 协议，完整应用身份认证和 Android 传输实现留待后续阶段。Compose 的 ON 显示由服务器确认后的状态决定。

## 本轮发现及关闭情况

1. **同一报价批次继续买入的问题已关闭。** QA 独立复现初始资金 2,000、两笔各 700 的挂单、bid 70/ask 100 时，首笔已触发回撤阈值，旧实现仍完成第二笔买入。修复后每笔成交立即重估风险并停止剩余批次。独立重跑得到一笔 BUY、一笔硬锁清仓 SELL，另一笔 BUY 取消，余额 1,790，重开账本仍锁定。价格跳变引起的已发生损失和触发后停止加仓分别在记录中体现。
2. **消费游标来源未绑定的问题已关闭。** 旧游标仅保存整数 ID，换库或恢复旧库可能跳过有效信号。现游标绑定策略路径、版本、影子文件、账户和 symbol，并核验对应 signal_id。来源不同明确拒绝，缺失或复用 ID 安全回退，通过账本持久幂等及过期筛选重新消费。
3. **拒绝误用数据库之前已经写入的问题已关闭。** 旧入口先创建策略表，再检查市场/策略路径冲突。现入口先检查路径和文件身份，各存储在初始化写入前检查已有表与所有权。回归覆盖错误文件拒绝后的文件字节、schema 或 journal mode 保持一致。
