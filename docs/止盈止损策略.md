# SOL-bot 止盈止损策略

本文描述当前代码里的 APTS 阶梯。手动托管和 Shadow 影子仓走同一套 `update_protection`。只做 SOL 现货多单，止损价只升不降。

托管仓每 15 秒看一次买一价。手续费按单边 0.075% 计，滑点按 0.075% 计。价格按 SOLUSDT 的最小跳动 0.01 取整。

## 四个阶段

| 阶段 | 进入条件 | 止损怎么放 | 什么时候卖 |
|---|---|---|---|
| S0 初始止损 | 开仓后 | 策略 `-1.0%` / 托管 `-0.8%` 向上取整（浮盈达 `+0.6%` 或连续 2-tick 持续反转时收紧 50%） | 买一价触及止损才卖；单次确认反转不提前卖 |
| S1 保底止盈 | 浮盈达到 0.8% | 止损抬到保本线之上 | 买一价回到保本线，或之后触及上移后的止损 |
| S2 移动止盈 | 浮盈超过 1.5% | 在保本线之上，再按高点回撤跟踪 | 跟踪止损被买一价碰到 |
| S3 趋势平仓 | 已经离开 S0，并且出现确认反转或剧烈逆向 | 沿用当时的止损，不再放宽 | 立刻改挂一张限价卖单 |

浮盈按买一价相对入场价计算，不含手续费。S1 的门槛是大于等于 1.0%。S2 的门槛是大于 1.5%。已经进入 S3 的仓不再退回前面的阶段。

## S0：初始止损

```
止损触发价 = 向上取整(入场价 × 0.992)
委托价     = 向下取整(触发价 × 0.997)
```

0.992 是向下 0.8%。0.997 是再让出 0.3%，让止损限价单有机会成交。

例：入场 83.31。

- 83.31 × 0.992 = 82.64352，向上取到 0.01，触发价 **82.65**
- 82.65 × 0.997 = 82.40205，向下取到 0.01，委托价 **82.40**

币安上是一张 SOLUSDT 的止损限价卖单。数量按持仓向下取到 0.001，尘埃留在账户里。

S0 期间如果买一价仍高于 82.65，即使判定为确认反转或剧烈逆向，也不卖、不改阶段、不撤这张止损单。界面记一笔「观察到反转，止损仍在」。只有买一价落到触发价或更低，才按这张单卖出。

## S1：保底止盈

浮盈达到 0.8%（`S1_PROFIT_PROTECTION_TRIGGER = 0.008`）后进入 S1。止损抬到保本线，并且不会再低于 S0 的止损。

```
保本线 = 向上取整( 入场价 × (1 + 买入费率) / ((1 - 卖出费率) × (1 - 滑点)) ) + 1 个跳动
```

托管使用的三个费率都是 0.075%：

```
保本线 = 向上取整(入场价 × 1.00075 / (0.99925 × 0.99925)) + 0.01
```

以 83.31 入场，保本线约为 83.48。买一价如果已经掉到这条线或更低，无法再把止损挂在市价下方，就直接卖出。

## S2：移动止盈

浮盈超过 1.5% 后进入 S2。止损取下面两个数里更高的一个：

- S1 的保本线
- 持仓以来最高买一价 × (1 − 跟踪距离)

跟踪距离由当时的市场状态决定：

| 状态 | 跟踪距离 |
|---|---|
| 强势突破 | 2 × ATR / 价格，限制在 0.8% 到 1.2% |
| 转弱 | 固定 0.4% |
| 其余，包括正常上涨 | 固定 0.5% |

强势突破要同时满足：4 小时、1 小时、15 分钟的 EMA20 都在 EMA50 之上，5 分钟量比至少 2 倍，买盘占比至少 60% 并且没有下降，1 分钟和 5 分钟都在抬高低点。

止损一旦上移，不再下移。

## S3：趋势平仓

只有已经离开 S0，确认反转或剧烈逆向才会升到 S3 并卖出。卖出时先撤掉原来的止损单，再挂一张限价卖单：

```
卖出限价 = 向下取整(买一价 × 0.997)
```

这张限价低于买一价约 0.3%，用来尽快成交，不是再等一个新的止损位。

### 确认反转

三件要同时成立，缺一不可：

1. 5 分钟收盘价跌破前三根 K 线最低价至少 0.5 个 ATR
2. 买盘占比低于 40%，并且比上一根更低
3. RSI(6) 比上一根至少低 8

### 剧烈逆向

三件同时成立：

1. 这一根的 ATR 大于上一根的 2 倍
2. 这一根收盘低于上一根
3. 买盘占比低于 40%，并且比上一根更低

S0 里即使满足这两类，也不卖。价格如果已经穿过 S0 止损，走的是止损成交，不走 S3。

## 谁在用这套规则

- 打开托管的手动 SOL 仓：下单后先挂 S0，之后每 15 秒按上面的阶梯上移或卖出。
- Shadow 影子仓：同一套计算。
- 实盘开关打开后的策略买单：成交后的保护也走这套阶梯。默认单笔 500–1000 USDT、最多 2 个策略仓，可在 App 实盘页「配置」弹窗中同步调整并应用到实盘与 Shadow 模拟盘。关闭开关不再开新仓，已经挂上的止损继续走完。

策略页上的 RSI、量比、VWAP、ATR 用来决定要不要买。它们不代替这里的止盈止损。系统已取消 12h 滞涨退场与 24h/120h 持仓时间强平限制——只要未触发止损或 S2/S3 动态止盈退场，仓位将一直持有。
