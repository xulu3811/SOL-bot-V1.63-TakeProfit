## 报告F：P3准备与尚缺输入

已可供数学阶段消费的输出：每交易对、策略版本、候选/确认/过期时间、市场状态、五周期指标、分项评分、价格区间、风险标记、完整来源范围与哈希、模拟订单/资金预留/成交/PnL。金额用Decimal字符串，UTC毫秒时间。

需要补齐的研究数据与模型：

1. 盘口：带交易所时间/本机接收时间的bid/ask和数量、点差、增量深度与快照校验、成交方向/成交量。现有最新bookTicker不足以估算排队和冲击。
2. 成交概率：候选创建、请求/响应延迟、价格距离、队列位置代理、撤单、未成交和部分成交样本；区分maker/taker费用。LIVE OFF期间不能为收集这些数据擅访私有接口。
3. 入场与退出：每标的波动率/滑点/延迟分布、条件成交概率、资金占用成本；在不可放宽300–700/两笔/5%等合同内评估。初始研究阈值须分别样本外验证。
4. APTS：接口现有初始止损0.008、利润保护0.01、adaptive_trigger0.015和NOT_IMPLEMENTED；未来需定义波动率状态、峰值权益/价格、单调保护边界、最小tick、间隔及跳空处理、保护单更新幂等性，避免假ALLOW。
5. 先补独立审计与数据留存/评分校准方案；R1继续永久禁止实盘，直到独立样本外验收与用户另行授权。

**阶段边界：仅交付P2。没有自动进入P3，没有连接主账户私有接口，没有真实交易。**
