# 报告C：入场价格、成交概率与动态仓位

## 入场及成本

既有 entry_pricing 使用盘口量加权微价格、信号价格上限、追价约束、预期收益上限及交易所 tick/lot/notional/percent filters，选择 passive / improved / marketable LIMIT。价格、数量向合法档位取整，不能突破购买上限。成本明确包含进出场费和滑点假设，关联上下文与源哈希必须一致。

生产公开 exchangeInfo 带有 PERCENT_PRICE_BY_SIDE 的5分钟参考约束。当前没有匹配参考窗口的公开均价证据，因此出现 PERCENT_PRICE_REFERENCE_MISSING 时拒绝；未用盘口中价冒充均价。手续费研究值不是查询私有账户所得费率。

## 概率与收益

fill_probability 输出完整/部分/无成交/超时分支、预期成交比例和不确定性；不可观测队列位置与未校准模型均明确标注。触价不代表100%成交。EV 使用条件收益形式 p×G−(1−p)×L−C，成本源和名义金额必须匹配。缺胜率或经独立审核的样本证据时返回不足，不用合成数据补齐实证资格。

## 动态仓位及边界

评分名义金额为 300+400×clip((S−75)/25,0,1)。实际预算取评分额度、700上限、账户风险额度、扣除预留和入场费后的可用金额的最小值，再按步长向下取整。低于300则拒绝，不能为满足最低额上调风险预算。

T1/R1 初始研究风险预算分别为净值0.4%/0.25%；分母计入初始0.8%保护距离、进出场费和滑点。最多两笔占用，部分买入的仓位与余单不能重复计数。净值相对高水位达到5%回撤时锁定新入场并取消买入余单，保留已有持仓及独立保护；重启不能清除该锁。

## 运行结果与权限

P3桥接复用P2调度检查点和候选去重，依次计算成本、成交估计、EV、仓位和价格；通过全部门槛才进入SOL影子执行器。生产目前仍缺实证成本/胜率和相应价格参考，数学门槛阻止新入场，审计记录实际拒绝原因。不能把“链路已接通”解释为“参数已获实盘许可”。

SUI的2000 USDT仅为明确标注的研究规划额度，不是私有账户余额。SUI没有影子SOL账本执行权；SOL-shadow不能使用SUI标的。R1实盘始终禁用，LIVE OFF，Guardian与订单保护完成前仍拒绝任何真实执行。
