# P4 报告C：虚拟资金与资产隔离

新增账户分配、资产归属、托管授权、资金预留、对账记录、仓位、退出预留及审计。初始2000 USDT是计划分配额，生产 `reconciled_at=0`、`equity_at=0`、`recovery_required=1`，没有伪造已核验的真实账户余额。

同一Binance主账户的币种余额在交易所仍合并，虚拟账本仅提供逻辑隔离。超出已知分配的资产归类为 MANUAL_UNMANAGED，不扩大机器人预算；余额不足、未知订单或未确认资产使对账进入 UNRECONCILED。原归属及仓位不被删除或重置。外部手动操作的实际发现依赖 P5 可信快照接入。

`CustodyPermissions` 管理明确资产、数量、身份、原因、有效期及撤销。卖出数量受授权归属数量与实际free余额双重限制，并扣除已有退出预留。未经授权的手动资产不能卖出；旧批准重复请求仍重验权限、有效期及新鲜度，不能在撤销后重用。托管到期/撤销后不会直接重分配可能仍在途的资产，而进入待对账。

`sell_fill` 只记录可信执行端已观察到的成交，不提交订单。机器人卖出收益回机器人现金；托管手动资产收益归手动USDT，不计入机器人资金。部分卖出按比例减少成本和风险，保留保护信息；成交事件幂等。

全部资金写入采用Decimal文本和SQLite事务。未知订单、取消待确认和BNB未知补充继续冻结资金。旧P3执行库与新账本物理隔离，旧执行器schema检查明确拒绝P4文件。没有读取Binance交易Secret或查询真实账户。

证据覆盖：手动SUI卖出拒绝、超卖拒绝、授权撤销、重复成交、部分退出、资金守恒、事务故障回滚、跨账户/标的、同意图变更、并发两笔700，以及备份恢复。
